# ガイド

Probe のワークフローは YAML ファイルです。ジョブとステップを並べ、レスポンスごとに検査を書きます。
このガイドはバイナリのインストールから始まり、複数の環境に対して動かすパイプラインまでを扱います。

- **はじめに** — インストールして、最初のワークフローを動かし、CLI を覚えます。
- **コンセプト** — ジョブ、ステップ、アクション、outputs、アサーションが実際に何をするのか。
- **やり方** — コーディングエージェントとの併用、API テスト、監視、環境管理、失敗時の扱いのレシピ集。
- **チュートリアル** — 動くものを最後まで組み上げる、長めの手順。
